# Course Builder - เครื่องมือสร้างแผนผังสนามแข่งขัน

เครื่องมือสร้างแผนผังสนามแข่งขันจักรยาน/รถ พร้อมฟีเจอร์ครบครัน:

- 🗺️ แผนที่ดาวเทียม (จาก Esri/Maxar)
- ✏️ ปรับขอบถนนแบบลากจุด
- 🚧 วางอุปกรณ์ (แบริเออร์, กรวย, จุด CP, ฯลฯ)
- 📸 ส่งออกภาพ PNG พร้อมเฟรมและคำอธิบาย
- 💾 บันทึก/เปิดไฟล์งาน (JSON)
- 📂 รองรับไฟล์ GPX
- ↩️ Undo/Redo (ย้อนกลับ/ทำซ้ำ)
- 🔗 แชร์ผ่านลิงก์ URL
- ⚡ Performance ดีเยี่ยมด้วย caching
- 🛡️ Error handling และ validation

## วิธีใช้บน GitHub Pages

### 1. สร้าง Repository บน GitHub
1. ไปที่ [GitHub](https://github.com) และสร้าง repository ใหม่
2. ตั้งชื่อตามต้องการ (เช่น `course-builder`)
3. เลือก **Public** เพื่อให้ใครก็ได้เข้าใช้งานได้

### 2. อัปโหลดไฟล์
1. ใน repository ให้อัปโหลดไฟล์:
   - `index.html` (ไฟล์หลัก)
   - `README.md` (ไฟล์นี้)

### 3. เปิดใช้งาน GitHub Pages
1. ไปที่ **Settings** → **Pages**
2. ที่ **Build and deployment** → **Source** เลือก **Deploy from a branch**
3. เลือก branch: `main` (หรือ `master`) และ folder: `/ (root)`
4. กด **Save**

### 4. รอสักครู่แล้วเข้าใช้งาน
- GitHub จะแจ้ง URL ของเว็บแอปของคุณ (เช่น `https://username.github.io/course-builder/`)
- เปิด URL ดังกล่าวเพื่อใช้งานได้ทันที

## ฟีเจอร์หลัก

### แท็บ "ถนน"
- **ลากปรับขอบ**: ปรับขอบถนนแบบลากจุดทีละจุด หรือปรับทั้งสองฝั่งพร้อมกัน
- **ขนาดถนน**: ปรับความกว้าง, เลื่อนเส้น, ความเรียบของเส้น
- **ปรับเป็นช่วง**: กำหนดค่าเฉพาะช่วงระยะทาง (เช่น โค้งแคบต้องเพิ่มความกว้าง)
- **รูปแบบเส้นขอบ**: เลือกลายเส้น (kerb, ขาว, เหลือง, เทป)

### แท็บ "อุปกรณ์"
- **วางทีละชิ้น**: คลิกวางอุปกรณ์บนแผนที่ ลากย้าย หมุน หรือลบ
- **วางเรียง**: วางอุปกรณ์เรียงตามแนวขอบถนนอัตโนมัติ
- **ชิ้นที่เลือก**: แก้ไขการหมุน, เพิ่มป้ายข้อความ, ทำซ้ำ, ลบ
- **อุปกรณ์ที่รองรับ**: กองฟาง, แบริเออร์ยาง, แบริเออร์ปูน, แบริเออร์น้ำ, กรวย, Start/Finish, จุด CP, จุดมาร์แชล, ชิเคน, หน่วยแพทย์, พื้นที่ผู้ชม, Pit

### แท็บ "ส่งออก"
- **บันทึกภาพ PNG**: สร้างภาพสำหรับ presentation พร้อมเฟรม, ทิศเหนือ, มาตราส่วน, คำอธิบายสัญลักษณ์
- **ไฟล์งาน**: บันทึกโปรเจกต์เป็น JSON เพื่อเปิดแก้ต่อได้
- **แชร์ลิงก์**: สร้างลิงก์ URL เพื่อแชร์ให้คนอื่นเปิดได้ทันที
- **เปิด GPX**: โหลดเส้นทางใหม่จากไฟล์ GPX

### แท็บ "ตั้งค่า"
- **Auto-save**: เปิด/ปิดการบันทึกอัตโนมัติ
- **ข้อมูลแอป**: ดูเวอร์ชันและข้อมูลเกี่ยวกับแอป
- **ล้างข้อมูล**: ล้างข้อมูลที่บันทึกไว้ใน localStorage

### ฟีเจอร์เพิ่มเติม
- **Undo/Redo**: ย้อนกลับ/ทำซ้ำการแก้ไข (Ctrl+Z / Ctrl+Y)
- **Auto-save**: บันทึกอัตโนมัติไป localStorage
- **Responsive**: รองรับทั้ง Desktop และ Mobile
- **Performance**: Cache ข้อมูล SVG และภาพสำหรับความเร็ว
- **Validation**: ตรวจสอบไฟล์ก่อนโหลดเพื่อป้องกัน error

## ทางลัดคีย์บอร์ด (Keyboard Shortcuts)
- `Ctrl+Z` - ย้อนกลับ (Undo)
- `Ctrl+Y` - ทำซ้ำ (Redo)
- `Esc` - ยกเลิกการวางอุปกรณ์
- `Delete` / `Backspace` - ลบอุปกรณ์ที่เลือก
- `Double-click` บนจุดจับ - คืนค่าเดิม

## เคล็ดลับการใช้งาน
1. **เริ่มต้น**: โหลดไฟล์ GPX ของเส้นทางที่ต้องการ
2. **ปรับขอบ**: ใช้ฟีเจอร์ลากปรับขอบเพื่อให้ตรงกับถนนจริง
3. **วางอุปกรณ์**: วางแบริเออร์และจุด CP ตามต้องการ
4. **ส่งออก**: บันทึกภาพ PNG พร้อมเฟรมสำหรับ presentation
5. **แชร์**: ใช้ปุ่ม "แชร์ลิงก์" เพื่อส่งให้ทีมงาน

## การแก้ปัญหา (Troubleshooting)
- **ภาพดาวเทียมไม่โหลด**: ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
- **GPX โหลดไม่ได้**: ตรวจสอบว่าไฟล์ GPX ถูกต้องและมีข้อมูลเส้นทาง
- **แอปทำงานช้า**: ลดจำนวนจุด GPS หรือใช้ไฟล์ GPX ที่เล็กลง
- **ไม่พบ undo/redo**: ตรวจสอบว่าทำการแก้ไขแล้วหรือยัง
